To reach the UI:
{{- if .Values.ingress.enabled }}
  https://{{ .Values.ingress.host }}/
{{- else if eq .Values.proxy.service.type "LoadBalancer" }}
  kubectl -n {{ .Release.Namespace }} get svc {{ include "bnk-forge.fullname" . }}-proxy
{{- else }}
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "bnk-forge.fullname" . }}-proxy 8443:443
  open https://localhost:8443/
{{- end }}

Admin login: username 'admin'. The password was generated on install — retrieve it with:
  kubectl get secret {{ include "bnk-forge.fullname" . }}-secrets -o jsonpath='{.data.admin-password}' | base64 -d
You will be required to change it on first login (the API refuses other calls until you do).

IMPORTANT:
  * Shared volumes use ReadWriteMany. Set global.sharedStorageClass to a
    RWX-capable StorageClass (NFS / EFS / CephFS / Azure Files / Filestore).
  * The proxy container runs as non-root (uid 101) and listens on 8080/8443.
